# MathMaster 1.0.5

## What's improved
- Start directly in the app without requiring login or registration.
- Keep Learning, Practice, Quiz, and Progress available in local guest mode.
- Save progress on the device; cloud authentication and synchronization are intentionally disabled for this offline-only release.
- Preserve existing signed APK identity, version, checksum, and update-feed verification.

## Android
- Application ID: `com.sudhanshu.mathsbj`
- Version: `1.0.5`
- Version code: `1140`

This release uses the existing app and device-local storage. No Supabase configuration is required to build the Android APK.
